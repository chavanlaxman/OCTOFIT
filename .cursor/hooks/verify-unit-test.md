# Verify unit-test policy (Cursor hook companion)

This file mirrors `.cursor/skills/verify-unit-test/SKILL.md` for humans and for prompt-hook context.

When Implementation or Verify touches tests, require:

- Tests Added Or Updated
- Behavior Covered
- Edge Cases Covered
- Command Run
- Execution Result
- Remaining Gaps

Do not claim PASS without executed coverage for testable behavior changes.
